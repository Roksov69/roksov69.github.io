Is a modern, interactive personal website built with pure HTML, CSS, and JavaScript. It features a cyberpunk aesthetic with a Matrix-style background, glassmorphism effects, and a fully functional simulated Python terminal.

The site is lightweight, responsive, and does not require any frameworks or third-party libraries to run.


## ✨ Features

The website offers an immersive user experience through the following features:

 🎨 **Visual Design & Atmosphere**
  - **Matrix Background**: Animated canvas rendering falling code characters (Katakana, Latin, symbols).
  - **Glassmorphism UI**: Modern translucent cards with blur effects (`backdrop-filter`).
  - **Ambient Lighting**: Dynamic radial gradients that create depth and mood.
  - **Responsive Layout**: Fully adaptive design for desktops, tablets, and mobile devices.

 💻 **Interactive Python Terminal**
  - A simulated command-line interface embedded in the page.
  - Supports commands like `help`, `status`, `hello_world`, `get_time`, `get_date`, and `clear`.
  - Window controls: Minimize, Maximize/Restore, and Close with smooth animations.
  - Expandable command panel for quick access to functions.

 🌍 **Multilingual Support**
  - Toggle the interface between **Russian (RU)** and **English (EN)**.
  - Instant text updates with fade transitions for role titles and bio descriptions.

 🔗 **Social Integration**
  - Direct links to YouTube, GitHub, and DonationAlerts.
  - Hover effects with glow and scale animations.

 ⚡ **Performance**
  - No external dependencies (except Google Fonts).
  - Optimized Canvas animation loop.
  - Lightweight codebase.
